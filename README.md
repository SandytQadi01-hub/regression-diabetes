# Linear & Polynomial Regression — Diabetes Dataset

نوتبوك واحد منفّذ بالكامل يغطّي الأجزاء 1-5: الانحدار الخطي، مقاييس التقييم
(يدويًا مقابل sklearn)، الانحدار متعدد الحدود، اكتشاف Overfitting/Underfitting،
وتطبيق أخير على بيانات حقيقية. كل الرسومات والنتائج ظاهرة داخل النوتبوك.

## الملفات
- `regression_diabetes.ipynb` — النوتبوك الكامل (منفّذ بالنتائج والرسومات).
- `regression_diabetes.html` — نسخة HTML للعرض بالمتصفح مباشرة.

## أبرز النتائج (متحقّق منها)
| البند | القيمة |
|-------|--------|
| Linear (كل المتغيرات) | MAE 42.79 · MSE 2900.19 · RMSE 53.85 · R² **0.453** |
| MAE/MSE يدوي مقابل sklearn | مطابق تمامًا ✅ |
| بيانات مصطنعة: خطي مقابل تربيعي | R² 0.42 → **0.89** (تحسّن كبير) |
| bmi وحده: خطي مقابل تربيعي | R² 0.233 → 0.229 (**لم يتحسّن**) |

## أهم الاستنتاجات
- **MSE يعاقب الأخطاء الكبيرة** أكثر من MAE، لذلك قد يكون MAE أقل بينما MSE أعلى
  بسبب أخطاء ضخمة قليلة.
- منحنى الأداء يوضّح **Underfitting** عند الدرجة 1 و**Overfitting** عند الدرجات
  العالية، وأفضل درجة ≈ 2 (البيانات تربيعية أصلًا).
- **Polynomial ليس دائمًا أفضل:** حسّن الأداء كثيرًا على البيانات المصطنعة، لكنه
  لم يُحسّنه على `bmi` الحقيقي لأن العلاقة قريبة من الخطية وفيها ضجيج.
